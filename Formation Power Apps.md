1- Personnaliser une application canevas dans Power Apps

Dans ce module, j'apprends à :

  modifier la disposition d’une galerie ;
  modifier les données affichées par un contrôle ;
  modifier un contrôle Formulaire pour afficher différents champs de données ;
  découvrir les contrôles Galerie et Formulaire ;
  ajouter un écran ;
  découvrir comment modifier les propriétés d’un libellé à l’aide de formules de base ;
  ajouter des libellés ;
  découvrir comment créer une navigation à l’écran de base.
